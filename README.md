🍔 Food Delivery Website

A responsive food delivery landing page built using HTML5 and CSS3. The website provides a modern interface for online food ordering, showcasing services, clients, and a contact section with a fully responsive design.

🚀 Features

✅ Responsive design for desktop and mobile devices

✅ Fixed navigation bar with smooth scrolling

✅ Hero section with call-to-action button

✅ Services section highlighting food ordering, catering, and delivery

✅ Client showcase section

✅ Contact form UI

✅ Modern layout using Flexbox

✅ Mobile-friendly experience with separate responsive stylesheet
